# Founders Studio - Pre-Launch Checklist

**Everything you need to do before you start selling.**

---

## WEBSITE & FUNNEL (Week 1)

- [ ] Homepage matches Executive Plan copy (7 sections only)
- [ ] Pricing shows Complete ($3,500) + Pro ($5,000) only
- [ ] "Who This Is/Isn't For" section is live
- [ ] All CTAs say "Apply to Launch Your Store"
- [ ] No VA services mentioned on homepage
- [ ] No AI explanations on homepage
- [ ] No hardware specs on homepage
- [ ] Mobile responsive tested
- [ ] All links work (no 404s)
- [ ] Analytics tracking installed

---

## APPLICATION PROCESS (Week 1)

- [ ] Application form created (13 questions)
- [ ] Green/Yellow/Red light scoring system built
- [ ] Auto-responses configured (3 types)
- [ ] Application data flows to CRM or spreadsheet
- [ ] You can access applications within 1 hour
- [ ] Test application submitted and reviewed

---

## SALES INFRASTRUCTURE (Week 1)

- [ ] Sales call script printed/bookmarked
- [ ] Calendar system for calls (Calendly or similar)
- [ ] Call template created (notes, objections, next steps)
- [ ] CRM or spreadsheet for tracking applicants
- [ ] Email template for follow-ups
- [ ] Phone number ready for calls

---

## PAYMENT & ONBOARDING (Week 1-2)

- [ ] Stripe account set up
- [ ] $3,500 and $5,000 products created
- [ ] Payment page tested (both amounts)
- [ ] Post-purchase email sequence created
- [ ] Onboarding checklist created (for customers)
- [ ] Welcome email template ready

---

## HARDWARE PREP (Week 2)

- [ ] Laptop(s) ordered (MacBook Air or Pro)
- [ ] Delivery timeline confirmed
- [ ] Setup checklist created (what to install, how to configure)
- [ ] Atlas account ready
- [ ] GPT training for Etsy completed
- [ ] Desktop organization template created
- [ ] Bookmarks preset (Etsy, tools, support)

---

## SUPPORT INFRASTRUCTURE (Week 2)

- [ ] Support email address created
- [ ] Support response template created
- [ ] Support hours defined
- [ ] Escalation process defined
- [ ] FAQ document started (based on common questions)
- [ ] Slack or communication channel set up for customers

---

## INTERNAL DOCS (Week 1)

- [ ] Internal Ops Doc finalized
- [ ] Sales Call Script finalized
- [ ] Application Questions finalized
- [ ] Onboarding playbook created
- [ ] Support playbook created
- [ ] Decision framework documented

---

## SOFT LAUNCH PREP (Week 2-3)

- [ ] Warm leads list created (people to reach out to)
- [ ] Email template for warm outreach ready
- [ ] Social media content calendar started
- [ ] First 5 case study templates created
- [ ] Daily sales screenshot process defined
- [ ] Short video script created ("another order came in")

---

## TESTING (Week 2-3)

- [ ] Full customer journey tested (application → payment → onboarding)
- [ ] All emails tested (application, payment, welcome, support)
- [ ] Payment process tested with real card
- [ ] Application scoring tested with sample data
- [ ] Sales call script practiced (with friend/colleague)
- [ ] Support response tested
- [ ] Hardware setup tested on actual laptop

---

## LAUNCH READINESS (Week 3)

- [ ] Website live and traffic flowing
- [ ] Application form live
- [ ] Payment system live
- [ ] Support email monitored
- [ ] Phone ready for calls
- [ ] First batch of warm leads contacted
- [ ] You've practiced the sales call at least 3 times

---

## WEEK 1 PRIORITIES (Do these first)

1. **Website** - Homepage live with correct copy
2. **Application** - Form live and scoring working
3. **Sales script** - Memorized and practiced
4. **Payment** - Stripe working for both tiers
5. **Support email** - Set up and monitored

---

## WEEK 2 PRIORITIES

1. **Hardware** - Ordered and delivery confirmed
2. **Onboarding** - Playbook created
3. **Warm leads** - List created and outreach started
4. **Testing** - Full customer journey tested
5. **Support infrastructure** - Email templates and escalation ready

---

## WEEK 3 PRIORITIES

1. **Launch** - Go live with warm leads
2. **Monitor** - Track applications, calls, conversions
3. **Iterate** - Adjust based on early feedback
4. **Document** - Update playbooks based on what you learn
5. **Prepare for scale** - Get ready for Phase 2

---

## RED FLAGS (Stop and fix before launch)

- ❌ Website has more than 7 sections
- ❌ Homepage mentions VA services
- ❌ Homepage explains AI in detail
- ❌ Pricing shows more than 2 options
- ❌ Payment system not tested
- ❌ Sales script not practiced
- ❌ Support email not monitored
- ❌ Application form has more than 15 questions
- ❌ No onboarding playbook
- ❌ No support infrastructure

---

## GREEN FLAGS (You're ready to launch)

- ✅ Website is calm and reassuring
- ✅ Application is short (3–5 minutes)
- ✅ Sales script is practiced
- ✅ Payment works smoothly
- ✅ Support email is monitored 24/7
- ✅ Onboarding playbook is ready
- ✅ Hardware is ordered/arriving
- ✅ Warm leads are identified
- ✅ You've tested the full customer journey
- ✅ You feel confident

## FIRST 30 DAYS METRICS

**Track these:**

- Applications received
- Application completion rate
- Calls scheduled
- Calls completed
- Conversion rate (calls → customers)
- Customer feedback
- Support tickets
- Hardware delivery status

**Goal:** First 5–10 customers, smooth onboarding, zero support disasters

---

## COMMON MISTAKES TO AVOID

- ❌ Launching with too many website sections
- ❌ Making the application too long
- ❌ Not practicing the sales script
- ❌ Launching without support infrastructure
- ❌ Not monitoring support email
- ❌ Explaining AI too much
- ❌ Showing hardware specs on website
- ❌ Offering free trials
- ❌ Selling to cold traffic directly
- ❌ Overcomplicating the onboarding

---

## SUCCESS LOOKS LIKE

After 30 days:

- 5–10 applications
- 3–5 calls scheduled
- 1–3 customers
- Zero support disasters
- Smooth onboarding process
- Clear feedback patterns
- Confidence in your offer

---

Ready to learn. Ready to iterate. Ready to support.
