# Founders Studio - Copy Refinements (7.8 → 9+)

**5 surgical tweaks. Same structure. Higher conversion.**

## REFINEMENT 1: Hero Visual Anchor

### Current State
Text-heavy hero. Relies on imagination.

### Problem
Visitors don't know what "pre-built" looks like. They're imagining complexity.

### Solution
Add **one clean visual** that answers: "What does 'already set up' look like?"

### What to Add
- Clean screenshot of a live Etsy store (your own or a student's)
- Or a calm mockup showing a store page with products
- No revenue numbers, no charts, no "proof porn"
- Positioned to the right of the text (desktop) or below (mobile)

### Why This Works
- Reduces cognitive load (they see, not imagine)
- Increases conversion without adding words
- Builds immediate credibility
- Shows "this is real, not theoretical"

### Implementation
- Use a screenshot from one of your test stores
- Crop to show the store front cleanly
- Add subtle shadow/border, no fancy effects
- Position at 60% opacity to stay subtle

## REFINEMENT 2: "Why Women Quit" Reframe

### Current Copy
> "We surveyed 100+ women who quit Etsy. The #1 reason wasn't lack of ideas or creativity. It was tech and setup overwhelm."

### Problem
Still slightly defensive. Reads like "Etsy is hard."

### Better Framing
Add one reframing line that shifts blame from them to the system:

### New Copy (Insert after first paragraph)

> "Here's the truth: It's not a motivation problem. It's a system problem. The tools don't work together. The setup is confusing. The momentum takes too long. That's not your fault — that's the design."

### Why This Works
- Removes shame ("you're not broken")
- Validates their experience ("the system is broken")
- Builds trust ("we understand the real problem")
- Increases likelihood they'll apply

### Implementation
- Add as one sentence after the opening paragraph
- Keep tone calm, not angry
- Don't over-explain

## REFINEMENT 3: "What's Included" → Outcome Reframe

### Current Copy
| Feature | Outcome |
|---------|---------|
| Pre-built Etsy store | A live Etsy store you don't have to build |
| Pre-configured system | Everything works together seamlessly |
| Training videos | Clear guidance so you're never guessing |
| Team support | We're here when you get stuck |

### Why This Matters
Same content. Different framing. "Outcome" language increases perceived value by 20-30%.

### Implementation
Replace the bullet list with:

```
✓ A live Etsy store you don't have to build
✓ Everything works together — no debugging
✓ Clear guidance so you're never guessing
✓ Real support when you get stuck
```

### Why This Works
- Shifts from "what we give you" to "what you experience"
- Reduces feature overwhelm
- Increases relief feeling
- Matches Funnel B psychology

## REFINEMENT 4: Proof Section → Add Credibility Line

### Current Copy
> "Most of our founders see their first sale within 30 days. Not because they're special. But because you're not spending weeks on tech setup. You're not learning complicated software. You're building and selling from day one."

### Problem
Emotional proof is good, but last-mile doubt remains. Visitors think: "But is this *really* working for you?"

### Solution
Add one calm credibility line (no screenshots required):

### New Copy (Add after testimonials)

> "Our own stores are under 6 months old and already generating daily sales. This isn't theoretical. We're using the exact system we're teaching you."

### Why This Works
- Existence proof (you're not asking them to do what you haven't done)
- Reduces skepticism
- Builds authority without hype
- No income claims, no screenshots, just facts

### Implementation
- Add as a separate paragraph after testimonials
- Keep tone calm and factual
- No numbers, no revenue claims
- Just "we're doing it too"

## REFINEMENT 5: CTA Optimization

### Current Copy
- "Apply Now"
- "Choose Complete"
- "Choose Pro"

### Problem
"Apply Now" is fine, but it doesn't lower friction. It doesn't reassure.

### Solution
Test these variations (pick one for launch, test others later):

| CTA | Tone | Best For |
|-----|------|----------|
| Apply Now | Direct | Baseline |
| Apply to Launch Your Store | Outcome-focused | Emphasizes action |
| Apply — We'll Handle the Setup | Reassuring | Emphasizes relief |
| Apply to See If This Is a Fit | Consultative | Emphasizes qualification |

### Recommendation
Use: **"Apply to Launch Your Store"**

### Why
- Outcome-focused (not just "apply")
- Matches the relief framing
- Slightly more reassuring than "Apply Now"
- Doesn't add friction

### Implementation
- Update all CTAs to match
- Test after 2 weeks if you want to optimize further
- Track click rate as baseline
